📦 Personal Plugin Server

Download and install personal extensions and plugins on any machine.

How to install on Google Chrome

  1. Click Download .zip for the extension above.
  2. Extract the downloaded .zip file to your preferred folder.
  3. Open Chrome and navigate to chrome://extensions.
  4. Toggle Developer mode in the upper right corner.
  5. Click Load unpacked and select the extracted folder.

How to install on IntelliJ IDEA / Android Studio / PyCharm

  1. Click Download .zip for the plugin above (do not extract the zip).
  2. In IntelliJ, open Settings (or Preferences on macOS: Cmd + ,).
  3. Select Plugins from the left menu.
  4. Click the gear icon (⚙️) at the top and select Install Plugin from Disk...
  5. Choose the downloaded .zip file and click Restart IDE if prompted.

How to install on macOS

  1. Click Download .dmg (or .zip) for the application above.
  2. For .dmg: Double-click to mount the disk image, then drag the application into your /Applications folder.
  3. For .zip: Double-click to extract the archive, then drag the .app file into your /Applications folder.
  4. Gatekeeper / Unsigned Developer Handling:
    If macOS alerts that the app cannot be opened because it is from an unidentified developer:
    • Finder: Right-click (or Control-click) the application in /Applications, select Open, and click Open in the confirmation dialog.
    • Terminal: Run xattr -cr /Applications/<AppName>.app to strip quarantine attributes.
